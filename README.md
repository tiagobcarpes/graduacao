# Repositório Acadêmico

Este repositório centraliza alguns códigos, exercícios e projetos desenvolvidos ao longo da graduação, a fim de documentar a evolução técnica, fixar conceitos e praticar a familiaridade e o controle de versão com Git.

## Tecnologias e Conceitos Praticados

*   **Lógica de Programação:** Estruturas condicionais, laços de repetição e manipulação de estruturas homogêneas (vetores e matrizes) utilizando **Pascal**.
*   **Desenvolvimento Web Básicos:** Criação de interfaces estruturadas com **HTML5**, estilização com **CSS3** e dinamismo com **JavaScript**.
*   **Versionamento:** Noções práticas de Git e fluxo de trabalho no GitHub.
